void store_destroy ( store_t *  store)

Frees the store and everything it owns.

Parameters
storeThe store to destroy. Does nothing if store is NULL.
Note
Destroys all three hash tables, which run their own destroy callbacks on every entry. Every item, shelf and cart is freed through those callbacks, so no separate free is needed.
Any pointer the caller still holds into the store becomes invalid after this call.

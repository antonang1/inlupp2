int event_loop ( store_t *  store)

Runs the menu loop, executing the user's chosen command until the user chooses to quit.

Parameters
storeThe store every command reads from and writes to.
Returns
Always 1. The value signals that the loop has ended, not whether anything succeeded.
Note
Dispatches the upper-cased menu character through an if/else chain against A, L, D, E, S, P, C, R, U, +, -, =, O and Q.
Only Q ends the loop, by setting run to false. Nothing else inside the loop can leave it.
